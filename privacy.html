Privacy Policy

Last updated: November 18, 2026

"gtaclip uploader" is a private tool used only by the owner of the Ankle Monitor Clips YouTube channel to upload that channel's own videos. It is not offered to the public.

What it accesses

  • YouTube upload permission (youtube.upload): to upload videos to the owner's own channel.
  • YouTube read-only permission (youtube.readonly): only to confirm which channel it is signed in to, so it never uploads to the wrong channel.

What it stores and shares

The sign-in token is stored only on the owner's own computer. The tool does not collect, sell or share any personal data, does not access anyone else's account, and sends nothing to any server other than Google's YouTube API.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
